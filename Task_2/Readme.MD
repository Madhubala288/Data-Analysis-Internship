# Retail Sales Analytics Dashboard

## Project Overview

This project presents an end-to-end Retail Sales Analytics solution that demonstrates the complete data analytics workflow, including dataset creation, data cleaning, exploratory data analysis, business insight generation, and interactive dashboard development using Microsoft Power BI.

The objective of this project is to transform raw retail transaction data into meaningful insights that support business decision-making.

---

## Project Objectives

* Create a realistic retail sales dataset.
* Clean and preprocess raw business data.
* Perform exploratory data analysis.
* Identify sales trends and customer behavior.
* Build an interactive Power BI dashboard.
* Generate business insights and recommendations.

---
